# proyecto-final-1
✨ True Beauty Salón & Spa

Sitio web oficial de True Beauty Salón & Spa

Plataforma web diseñada para presentar servicios de belleza, productos profesionales, administrar un inventario y facilitar las compras mediante un carrito interactivo con generación de recibos.

📌 Descripción del proyecto

True Beauty Salón & Spa es una página web moderna, elegante y adaptable a dispositivos móviles, desarrollada para ofrecer a los clientes una experiencia digital completa.

El sitio permite conocer los servicios del salón, consultar productos de belleza, revisar métodos de pago, visualizar información de contacto y realizar pedidos mediante un carrito de compras.

El diseño utiliza una combinación de tonos rosa, rojo suave, dorado y blanco para transmitir elegancia, profesionalismo y bienestar.

💻 Instalación y ejecución

No es necesario instalar dependencias ni configurar un servidor para visualizar la versión actual.

Paso 1. Descargar o clonar el proyecto.

bash
git clone URL_DEL_REPOSITORIO


Paso 2. Ingresar a la carpeta.

bash
cd True-Beauty-Salon


Paso 3. Abrir el archivo index.html en un navegador web.

⚙️ Funcionamiento del sistema

La aplicación utiliza JavaScript para administrar las funciones principales:

renderCatalog(): muestra los productos y servicios.
filterCatalog(): filtra los elementos del catálogo.
renderInventoryTable(): muestra el inventario.
updateStock(): modifica las existencias.
addToCart(): agrega artículos al carrito.
updateCartQuantity(): modifica las cantidades.
removeFromCart(): elimina artículos.
updateCartUI(): actualiza los valores del carrito.
openReceiptModal(): genera el recibo.
printReceipt(): permite imprimir el recibo.
copyToClipboard(): copia información de las cuentas bancarias.
⚠️ Consideraciones técnicas

Esta versión funciona como una demostración frontend.

Los productos y servicios están definidos directamente en JavaScript.
Los cambios de inventario no se guardan permanentemente.
El carrito no utiliza una base de datos.
Los recibos se generan en el navegador y no constituyen comprobantes fiscales electrónicos.
Los métodos de pago son informativos; no existe una pasarela de pago integrada.
Las imágenes, fuentes y algunos recursos dependen de servicios externos.

Para convertirlo en un sistema comercial completo se recomienda integrar una base de datos, autenticación de usuarios, un backend y una pasarela de pagos segura.
